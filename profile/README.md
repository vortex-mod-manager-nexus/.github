## Getting Started Playbook

Install the manager, let it detect supported games, and link the mod site account. Choose the deployment method that matches the game, since some games behave better with hardlinks. Start with a small number of mods and one profile.

Create a vanilla profile alongside your modded one before adding anything. Read Vortex reviews about deployment on your game and check the conflict view after each install. Purge and redeploy after a game update to confirm the setup still works.

## Troubleshooting Common Issues

Install issues? Deploy to the same drive as the game, since cross-drive hardlinks fail.  
Performance problems? Purge before changing the deployment method.  
License/activation? Check that the game plugin is enabled for the specific title.  
Compatibility? Redeploy after a game update that restores original files.  
Update failures? Read the deployment log when files report as missing.
